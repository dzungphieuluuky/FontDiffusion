# FontDiffuser Architecture Evolution Comparison

This table compares the progression of the FontDiffuser models across iterations, detailing how each phase builds upon the previous to resolve specific limitations in font style transfer.

| Model Iteration | Core Innovations | Important Modules | Key Training Parameters |
| :--- | :--- | :--- | :--- |
| **1. Base FontDiffuser** | **Decoupling Content & Style:** Demonstrated that fonts could be generated via diffusion by independently encoding a standard font reference and a target font image.<br><br>_Limitation:_ Base U-Net struggles to preserve stroke topology on complex Chinese/Nom characters. | • **Content / Style Encoders:** Extractor networks mapped to U-Net cross-attention layers.<br>• **U-Net:** The diffusion backbone.<br>• **SCR:** A pre-trained network used in Phase 2 to enforce style similarity. | • `--phase_1` / `--phase_2`<br>• `--drop_prob` (standard CFG dropout to zeros)<br>• `--sc_coefficient` (Weight for SCR style contrastive loss) |
| **2. FontDiffuser + FST** | **Explicit Feature Transformation:** Maps multi-scale style features to content features using a transformer querying system before they reach the U-Net. This preserves complex structures.<br><br>_Limitation:_ Diffusion artifacts can still appear around sharp edges or empty spaces. | • **MultiScaleStyleEncoder (MSS):** Extracts style at multiple resolutions.<br>• **FST Module:** Uses cross-attention to inject multi-scale style maps.<br>• **Identity / Consistency Modules:** Contrastive losses for generated vs real pairs. | • `--use_fst`<br>• `--fst_num_queries` & `--fst_num_scales`<br>• `--num_consistency_pairs` & `--num_identity_pairs`<br>• `--consistency_loss_weight` / `--identity_loss_weight` |
| **3. FontDiffuser + FST + FFT** | **Frequency-Guided Generation:** Separates the target glyph into low, mid, and high frequency bands in the Fourier domain. Low bands guide layout, high bands guide sharp edges and serifs.<br><br>_Limitation:_ Susceptible to "style-content entanglement" where the model accidentally copies content strokes instead of actual style. | • **FrequencyDecomposition:** Applies filters in the Fourier domain.<br>• **Auxiliary Losses:** Component that applies separate generation constraints on low/high frequency maps to prevent smearing. | • `--use_frequency_decomp`<br>• `--frequency_low_cutoff` & `--frequency_mid_cutoff`<br>• `--use_aux_losses` |
| **4. FontDiffuser + FST + FFT + UniCalli** | **Robust Disentanglement Conditioning:** Fixes entanglement by decoupling noising schedules (keeping content perfectly clean) and aggressively penalizing entanglement using "hard-negative" CFG dropouts instead of pure noise. | • **AsymmetricNoisingScheduler:** Noises the target, protects the content, lightly augments style.<br>• **ConditionalDropoutAugmentation:** Drops style and content independently with a curriculum and replaces them with mismatched batch elements (hard negatives). | • `--style_noise_fraction`<br>• `--p_drop_content` & `--p_drop_style`<br>• `--use_hard_negative`<br>• `--curriculum_steps` |
